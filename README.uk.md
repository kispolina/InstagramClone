# YUNO — фронтенд-макет авторизації

Застосунок наразі запускає лише інтерфейсні макети входу, реєстрації, відновлення пароля та початкового налаштування профілю. Firebase, API, серверні сервіси й збереження даних не підключені. Введені значення існують тільки в пам’яті застосунку й зникають після перезавантаження.

## Запуск

```bash
npm install
npx expo start --web --clear
```

Для запуску на iOS або Android використайте `npx expo start --ios` чи `npx expo start --android` за наявності відповідного середовища. Використовується Expo SDK 54.

## Поведінка макета

- Форми входу, реєстрації, відновлення пароля та анкети профілю демонструють навігацію й локальну валідацію.
- Кнопки входу та реєстрації не створюють акаунт і не звертаються до сервера.
- SMS, листи підтвердження та листи відновлення не надсилаються.
- Фото профілю можна вибрати локально; воно не завантажується.
- Тести валідації: `npm test`.

Під час підключення бекенду додайте його окремо; не зберігайте паролі чи токени у фронтенді.

# YUNO — тільки frontend-макети

Це Expo/React Native прототип екранів входу, відновлення пароля, реєстрації, профілю та переходів між ними.

**Без Firebase, бекенду, API або services.** Усі значення залишаються тільки в пам’яті інтерфейсу під час відкритої сесії. SMS і листи не надсилаються, акаунти не створюються, дані профілю не зберігаються.

## Запуск

```bash
npm install
npx expo start --web --clear
```

Основний застосунок у кореневому `App.js` використовує цей прототип як інтерфейс. Підключення бекенду має виконуватися окремо, коли воно буде готове.

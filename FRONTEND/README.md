# YUNO — тільки frontend-макети

Це окремий Expo/React Native прототип екранів входу, відновлення пароля, реєстрації, профілю та переходів між ними.

**Без Firebase, без бекенду, без API, без services, без .env.** Усі введені значення зберігаються тільки в пам’яті інтерфейсу під час відкритої сесії. Коди SMS не надсилаються, акаунти не створюються, паролі не перевіряються на сервері.

## Запуск
```bash
npm install
npx expo start --web --clear
```

Це самостійний UI-прототип. Не замінюйте ним `App.js` командного репозиторію без узгодження: той файл містить робочу логіку Firebase. Для роботи в команді краще переносити UI-компоненти та стилі окремо.

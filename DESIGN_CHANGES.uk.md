# YUNO — оновлений дизайн авторизації

Оновлено `App.js` під надані дизайнерські скриншоти (фіолетовий фон, лаймовий логотип YUNO, кнопки, інпути, навігація між екранами).

## Запуск

```bash
npm install
npx expo start --web --clear
```

Для iOS: `npx expo start --ios` за наявності налаштованого симулятора.

Конфігурацію Firebase JS SDK програма бере з `EXPO_PUBLIC_FIREBASE_*` у `.env`. Увімкніть Email/Password у Firebase Console → Authentication → Sign-in method. У проєкті використано `App.js`, а не `App.tsx`.

## Працює

- Вхід email + пароль через Firebase.
- Реєстрація email + пароль через Firebase і запит листа підтвердження.
- Відновлення пароля через Firebase.
- Переходи між формами, перевірка email, дати, пароля, нікнейму.
- Зміна displayName у Firebase після проходження анкети.

## Що лишається підключити

- Реальне SMS/OTP для телефону: потрібні Firebase Phone Authentication і перевірка застосунку (reCAPTCHA для web, налаштування iOS/Android). Кнопка не генерує фальшивий код і пояснює недоступність, тому для реєстрації використовуйте email.
- Firestore для профілю, імені користувача, дати та інтересів; вибір фотографії зараз локальний, без завантаження у Storage.
- Повноцінна стрічка й профіль після реєстрації: екран «Все готово!» існує як заглушка.

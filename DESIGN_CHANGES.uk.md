# YUNO — макети входу та реєстрації

Основний застосунок у кореневому `App.js` відображає UI-прототип із `FRONTEND/App.js`. Візуальна система використовує фіолетовий фон, лаймові акценти та логотип YUNO (`FRONTEND/assets/yuno-logo.png`).

Вхід, реєстрація й відновлення пароля — лише інтерактивні макети. Валідація виконується локально; жодні облікові записи, повідомлення чи дані профілю не створюються та не надсилаються. Не додавайте інтеграцію з бекендом до цього UI без окремого узгодження.

Запуск: `npx expo start --web --clear`. Перевірка: `npm test` та `npx expo export --platform web`.

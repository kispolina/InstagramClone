# Firebase підключено до екранів

Актуальна інструкція налаштування і перевірки — у README.uk.md.

App.js викликає функції services/backend.js. services/firebase.js ініціалізує Firebase з .env лише за першого запиту. За відсутності конфігурації помилка показується в інтерфейсі. Подвійні натискання під час запиту блокуються. Перехід після входу або збереження профілю відбувається після успішної відповіді Firebase.

Для іншого власного Web API можна отримати ID token через getBackend().auth.currentUser.getIdToken() і передавати як Authorization: Bearer. Сервер повинен перевіряти цей токен через Firebase Admin SDK; серверних ключів у застосунку бути не повинно.

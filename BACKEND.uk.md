# Підключення бекенду — не реалізовано

Поточний `App.js` є UI-макетом без Firebase, API, серверних сервісів або збереження даних. Екрани показують лише демонстраційні заглушки.

Коли команда буде готова до бекенду, його слід спроєктувати й реалізувати окремо від UI. Не зберігайте паролі, приватні ключі чи токени у клієнтському застосунку.

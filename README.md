# YUNO

Expo / React Native застосунок за макетом Figma: вхід, реєстрація, відновлення пароля, код підтвердження, дата народження, нікнейм, фото профілю та головна сторінка зі стрічкою.

Це тільки інтерфейс: бекенду немає, дані зберігаються в пам'яті, код підтвердження приймається будь-який із 4 цифр.

## Запуск

```bash
npm install
npx expo start --web --clear
```

Перевірка валідації: `npm test`.

## Структура

- `App.js` — перемикає вхід та головну сторінку
- `screens/Auth.js` — усі екрани входу й реєстрації
- `screens/Home.js` — головна: сторіз, стрічка, таб-бар, профіль
- `ui.js`, `DateWheel.js`, `theme.js` — спільні компоненти й кольори з макета
- `validation.js` — перевірка пошти, телефону, дати народження

## Що не перенесено з макета

- Фото й відео зі стрічки замінені кольоровими заглушками (завантажити їх із Figma не вдалося).
- Шрифти Rubik та Inter не підключені, використовується системний шрифт.
- Темна тема головної сторінки не реалізована, тільки світла.
- Розділи «Рілси», «Створити» й «Пошук» у таб-барі показують заглушку.
